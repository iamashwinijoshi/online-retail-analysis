# Online Retail Data Analysis and Customer Prediction

## Project Overview
This project analyzes an online retail dataset using Python and machine learning. It explores sales trends, customer purchasing behaviour, customer segmentation, and the prediction of repeat purchases.

## Objectives
- Clean and preprocess retail transaction data.
- Analyze monthly revenue, top-selling products, purchase frequency, and revenue by country.
- Segment customers using RFM analysis and K-Means clustering.
- Build machine learning models to predict whether a customer will make another purchase within the next 30 days.

## Modules Completed

### Module 1: Data Collection and Cleaning
- Loaded the Online Retail dataset using Pandas.
- Identified missing values and duplicate records.
- Excluded cancelled invoices and prepared a cleaned dataset.

### Module 2: Exploratory Data Analysis (EDA)
- Analyzed monthly revenue.
- Identified top-selling products.
- Examined customer purchase frequency.
- Compared revenue across countries.
- Created visualizations using Matplotlib and Seaborn.

### Module 3: Customer Segmentation
- Calculated Recency, Frequency, and Monetary (RFM) metrics.
- Applied K-Means clustering to group customers based on purchasing behaviour.

### Module 4: Predictive Machine Learning
- Built Logistic Regression and Random Forest classification models.
- Created a target for purchases within the next 30 days.
- Evaluated model performance using a chronological train/test approach.
